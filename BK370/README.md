# BK370 · ESP32-S3

На кожній каретці два GM25-BK370 12 В (1:9,3), MDD3A, окремі енкодери A/B, INA226, серво й RGB LED.

| PlatformIO | Arduino IDE | Призначення |
|---|---|---|
| single | BK370_Single | Одна каретка із сайтом |
| main | BK370_Main | Каретка 1 із сайтом та ESP-NOW |
| remote | BK370_Remote | Каретка 2 з ESP-NOW |

[Схема підключень](WIRING.md) · [Логіка та обмеження](ARCHITECTURE.md)

**PlatformIO.** Відкрийте папку BK370 і виберіть профіль. Для Arduino IDE встановіть Arduino ESP32 3.3.12, ArduinoJson 7.4.3 і WebSockets 2.7.2. Скопіюйте library.properties і папку src у бібліотеку libraries/BK370Carriage в Arduino Sketchbook. Відкрийте скетч відповідної ролі. Плата ESP32S3 Dev Module, Flash 16 MB, QIO 80 MHz, OPI PSRAM.

**Телефон.** Під’єднайтеся до Motor-Control (початковий пароль motor8266) і відкрийте [motor-control.local](http://motor-control.local/) або [192.168.4.1](http://192.168.4.1/). Для парного режиму зчитайте station MAC обох плат у Serial Monitor (115200), внесіть MainMac та RemoteMac у Settings.h і перепрошийте обидві. Ланцюжок на сайті застосовує команду до обох кареток. Кожна плата контролює свою батарею й двигуни.

**Перший запуск.** DriveCommissioned=false залишає моторний і сервопривідний виходи вимкненими. Перевірте INA226, ESP-NOW і обидва енкодери ручним обертанням. Налаштуйте reverseEncoder і reverseMotor для кожного каналу, щоб рух вправо збільшував обидва лічильники. Вмикайте DriveCommissioned після перевірки живлення та апаратного обмеження струму.

**Калібрування.** Для кожного двигуна окремо поділіть модуль різниці показників енкодера на виміряну рулеткою відстань у метрах і запишіть результат у countsPerMeter. Нульовий коефіцієнт блокує команди у метрах. Після перезапуску вручну встановіть каретку по центру й позначте центр на сайті. Для замірів передбачені тести на 1, 2, 5 і 10 с.

**Батарея.** 10,0 В = 0%, 12,4 В = 100%. Три послідовні виміри на рівні 10,24 В або нижче фіксують блокування. При втраті показників INA226 приводи зупиняються. Для скидання блокування потрібні щонайменше 10,50 В і явна команда з сайту. Рух після скидання запускається новою командою. Оцінка заряду орієнтовна й не гарантує відсічення раніше за BMS при розбалансованих комірках.
