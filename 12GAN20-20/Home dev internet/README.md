# Home dev internet

Для **ESP32-S3** відкрийте [інструкцію Home-профілів](2_Carriages_WebSite/README.md). У парній версії обидві плати підключаються до домашньої мережі 2,4 ГГц і обмінюються командами через ESP-NOW. Назву й пароль задайте на початку основного файлу `.ino` для кожної плати. Для однієї ESP32-S3 задайте ці значення у [single_home_esp32s3.cpp](../PlatformIO/src/single_home_esp32s3.cpp).

Після підключення відкрийте [сайт каретки](http://motor-control.local/) з пристрою в тій самій мережі. IP-адресу можна подивитися в Serial Monitor або у списку клієнтів роутера.

Готова копія скетчу NodeMCU для Arduino IDE знаходиться у папці `NodeMCU`. Відкривайте файл `NodeMCU/NodeMCU.ino`; назву мережі та пароль вводьте безпосередньо у верхній частині `NodeMCU/config.h`.

Ця копія NodeMCU відрізняється від основної прошивки: вона працює тільки в режимі `STA`, тобто не створює мережу `Motor-Control` і підключається лише до домашнього Wi‑Fi.

Особистий пароль зберігайте у своїй копії прошивки.
